Привет 👋 Как это работает

  • Каждая карточка — токен. Спред — насколько цена отличается между самым дешёвым и самым дорогим местом прямо сейчас.
  • min / max — где именно дешевле и где дороже.
  • Чистыми на $X — оценка прибыли после всех комиссий и газа. Это оценка, не гарантия — тапните на карточку, чтобы увидеть детали.
  • ★ — закрепить токен наверху списка. 🔥 — спред выше вашего порога.
  • 🛡️ Проверить на honeypot — узнать, не окажется ли токен ловушкой, из которой нельзя продать.
  • 🦊 Открыть своп — открывает Uniswap с этим токеном, подключается через MetaMask/Trust Wallet.
  • Ползунок наверху фильтрует список — остальные настройки спрятаны под «⚙️ Дополнительные настройки».

⚠️ Это информационный инструмент, не финансовый совет. Спред и прибыль — оценка на момент обновления; реальный результат сделки зависит от глубины рынка в моменте. Решение всегда за вами.

Токены
CEX (7 бирж): Binance, OKX, Bybit, Gate.io, MEXC, CoinEx — низкие комиссии (~0.1%); Crypto.com добавлен для более широкого покрытия и сверки, но у него базовая комиссия выше (~0.4%, если не стейкать CRO) — учитывайте это в расчёте прибыли. Список токенов (до 500) строится динамически — берутся живые топ-500 пар по 24-часовому объёму на Binance (без стейблкоинов и плечевых токенов), а не набиты руками. DEX (топ-10 реальных AMM): Uniswap, PancakeSwap, SushiSwap, Curve, Balancer, KyberSwap, QuickSwap, Trader Joe, Raydium, Orca — через публичный API DexScreener. Пулы с ликвидностью ниже $20 000 и цены, аномально отклоняющиеся от медианы CEX, отбрасываются автоматически. Проверка на honeypot — через GoPlus Security API, доступна для токенов на Ethereum/BSC/Polygon/Avalanche. Цифра рядом с биржей в развёрнутой карточке — отклонение её цены от медианы всех источников; заметно просевшие отмечены красным. ★ добавляет токен в избранное (сохраняется в этом браузере). Метки сетей — ориентировочные. Можно добавить на домашний экран как приложение (Поделиться → На экран «Домой» в Safari, или меню браузера → Установить приложение на Android).
